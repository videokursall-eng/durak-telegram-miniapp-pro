# Replit — быстрый прототип/демо

Replit удобен для:
- показать демо заказчику
- поднять прототип WS
- отладить сборку

## Как использовать с этим репо
1) Импортируй GitHub репозиторий в Replit.
2) Включи `pnpm` (если доступно) или используй `npm`.
3) Запускай `apps/web` отдельно как фронт демо.
4) Для мультиплеера лучше держать server отдельно (Render/Fly), а Replit — только UI.

⚠️ Для продакшна лучше Cloudflare Pages/Vercel + отдельный backend.
