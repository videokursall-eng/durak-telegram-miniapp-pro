# Арт-бриф (Midjourney / Leonardo) — Durak PRO

## Стиль
- “modern casino felt table”, premium, clean UI
- 2D ассеты, лёгкие тени, без перегруза
- Цвета должны хорошо смотреться в dark mode Telegram

## Набор ассетов (MVP)
1) Стол (background) 2–3 варианта
2) Колода (back design) 3 варианта
3) Лицевая сторона карт (можно использовать стандартный дизайн, но лучше сделать свой)
4) Иконки:
- attack, defend, transfer, take, beat
5) Микроэффекты:
- glow selected card
- confetti win (опционально)

## Экспорт
- PNG (2x) + SVG где возможно
- Папки:
  - `apps/web/src/assets/table/`
  - `apps/web/src/assets/cards/`
  - `apps/web/src/assets/icons/`
