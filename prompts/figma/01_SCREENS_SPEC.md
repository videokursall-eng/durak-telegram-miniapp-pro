# Figma — спецификация экранов

## Welcome
- Лого/название
- CTA: Играть
- Переключатель режима: Простой / Переводной
- Ссылка: Правила

## Lobby (Matchmaking)
- Выбор: Быстрая игра / Комната
- Настройки: режим, число игроков (auto/2/3/4/5/6)
- Статус поиска

## Room
- список игроков + ready
- кнопка “Старт” у владельца
- invite link

## GameTable
- стол (felt)
- игроки вокруг
- центр: table pairs
- справа/снизу: action bar
- сверху: статус матча (кто ходит)
- мини-панель: козырь/колода/отбой

## Result
- победитель(и) + “дурак”
- кнопки: сыграть ещё, выйти
