# GitHub Copilot — как применять в проекте

Copilot лучше всего использовать на уровне:
- написания небольших функций
- автодополнения, типизации
- быстро накидать валидаторы и парсеры

## Практика
1) Держи открытым `docs/RULES_DURAK.md` и `docs/WS_PROTOCOL.md`
2) Пиши сначала сигнатуры и типы — Copilot хорошо подхватывает
3) Для сложных вещей (FSM, applyAction) — лучше Cursor + тесты
