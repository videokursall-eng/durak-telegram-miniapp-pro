# PRD — Telegram Mini App «Дурак: простой + переводной» (PRO)

## 1. Цель продукта
Создать коммерческую Telegram Mini App (Mini Game) для игры в **Дурака**:
- **Простой (подкидной)** и **Переводной** режимы в одном приложении.
- Матчи от **2 до 6 игроков**.
- Быстрый старт в 2–3 тапа, стабильная работа в Telegram, reconnect без потери матча.
- Базовая монетизация (косметика) и фундамент под турнирные режимы.

## 2. Пользователи и сценарии
### 2.1 Основные сценарии
1) **Быстрая игра** (matchmaking):
- пользователь жмёт «Играть»
- выбирает режим (простой/переводной), количество игроков (авто)
- попадает в матч

2) **Комната по ссылке**:
- создатель создаёт комнату
- делится ссылкой в чате
- друзья заходят и стартуют матч

3) **Игра с ботами** (опционально v2):
- пользователь выбирает число ботов
- игра начинается без ожидания других игроков

### 2.2 Вторичные сценарии (после MVP)
- Рейтинги, статистика
- Турнирные столы
- Магазин косметики (стол, рубашки, эффекты)

## 3. Платформы и ограничения
- Telegram iOS/Android/Desktop.
- Встроенный браузер Telegram + ограничения памяти/CPU.
- Требования:
  - HTTPS
  - корректная работа при сворачивании/возврате
  - корректный reconnect WS

## 4. Фичи (MVP)
### 4.1 Игровой стол
- Игроки по кругу (2–6), для каждого:
  - имя
  - количество карт в руке
  - метка «атакует/защищается»
  - индикатор текущего хода (таймер опционально)
- Центр стола:
  - пары карт атака/защита (до лимита)
  - козырь (открытая карта + масть)
  - колода (кол-во карт)
  - отбой (кол-во)
- Панель действий:
  - **Ход** (атаковать/подкинуть выбранными картами)
  - **Покрыть** (защититься выбранной картой)
  - **Перевести** (только в переводном режиме и при валидных условиях)
  - **Бито** (закончить успешную защиту)
  - **Беру** (взять карты со стола)

### 4.2 Игровая логика
- Движок правил живёт в `/packages/shared` как чистая функция:
  - `applyAction(state, action) -> {state} | error`
- Сервер является источником истины:
  - клиент отправляет intention
  - сервер валидирует, применяет и рассылает новое состояние

### 4.3 Мультиплеер
- WS соединение
- Комнаты/матчи
- Снапшот состояния при входе/рекавери
- Защита от двойных действий (idempotency через `actionId`)

### 4.4 Telegram интеграция
- Получение пользователя из `initData`
- Установка темы (под Telegram theme params)
- MainButton/BackButton (опционально)

## 5. Нефункциональные требования (PRO)
- Reconnect: при разрыве/возврате пользователь должен восстановить матч ≤ 3 сек.
- Производительность: 60fps (по возможности), без лагов на устройствах среднего уровня.
- Отказоустойчивость: сервер не падает на некорректных действиях.
- Наблюдаемость: логи матчей, ошибки (Sentry), метрики (опционально).
- Безопасность: строгая проверка `initData`, защита WS, rate limiting.

## 6. Монетизация (v1)
- Косметика:
  - стол (themes)
  - рубашки карт
  - эффекты (анимации «Бито», «Победа»)
- В будущем:
  - VIP-подписка (статистика, эксклюзивные темы)
  - турниры (вступительный взнос)

## 7. MVP-этапы релиза
### Stage 0 — Scaffold
- Репозиторий + документы + окружение dev (frontend + server + shared)

### Stage 1 — Simple Durak 2p
- простой режим на 2 игрока
- базовый стол, без сложных анимаций
- основные действия и корректный конец матча

### Stage 2 — Simple Durak 2–6p
- увеличение до 6 игроков
- подкидывание от других игроков

### Stage 3 — Transfer Durak
- переводной режим (2p → затем 2–6p)
- полный набор edge cases

### Stage 4 — Полировка PRO
- анимации, звук, UX
- reconnect/таймауты
- аналитика/ошибки
- деплой и QA

## 8. Метрики успеха
- D1 retention, средняя длительность сессии
- % матчей, завершённых без ошибок
- конверсия в косметику

## 9. Определения
- **Простой/подкидной**: атакующий подкидывает карты, защитник отбивается или берёт.
- **Переводной**: защитник может перевести атаку при наличии карты того же ранга.
